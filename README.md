# Лендинг IIRuChating — iiruchating.ru

Статический одностраничный сайт компании и бренда **IIRuChating**.
Основной продукт в линейке — **AI Ru Chating** (корпоративный мессенджер с локальным
AI-ассистентом).

Собран на чистом HTML/CSS/JS: без сборщиков, фреймворков и внешних CDN.
Шрифты и графика лежат внутри репозитория — сайт полностью автономен.

---

## Структура

```
.
├── index.html                  # главная (единственная страница)
├── 404.html                    # страница «не найдено»
├── robots.txt
├── sitemap.xml
├── .htaccess                   # Apache: 404, gzip, кэш, заголовки
└── assets/
    ├── css/
    │   ├── styles.css          # вёрстка лендинга
    │   ├── theme-m3.css        # роли Material 3 из брендбука (не редактировать)
    │   └── fonts.css           # @font-face, self-hosted (не редактировать)
    ├── js/main.js              # тема, навигация, появление блоков, форма
    ├── fonts/*.woff2           # Inter, Manrope, Montserrat (latin + cyrillic)
    └── img/                    # логотипы, favicon, PWA-манифест из брендкита
```

`assets/css/theme-m3.css`, `assets/css/fonts.css` и `assets/img/` — копии из
[`iilmchat/ai-brand`](https://github.com/iilmchat/ai-brand) (брендбук v1.1).
При обновлении брендкита копируйте их заново и не редактируйте руками.

## Публикация на reg.ru

### Схема (рекомендуемая)

Домены и сайт живут на уже оплаченном виртуальном хостинге **Хост-0** (`u3692326`):
7 сайтов, 13 ГБ (файлы сайта и почта), почта и PHP включены, дата-центр в России —
это закрывает обязательное требование зоны `.ru` (хостинг в РФ).

| Домен | Роль | Где смотрит |
|-------|------|-------------|
| `iiruchating.ru` | сайт компании и бренда | этот проект |
| `ai-ru-chating.ru` | сайт продукта AI Ru Chating | позже: папка рядом на том же хостинге |
| `ruchating.ru` | короткий алиас | 301-редирект на `iiruchating.ru` |

Занято 4 из 7 сайтов (`arkhivedela.ru` + три новых), запас есть.

### Что нажимать в корзине при регистрации домена

| Позиция | Действие | Почему |
|---------|----------|--------|
| Домен `.ru` на 1 год (169 ₽) | **взять** | 169 ₽/год, продление с 01.04.2026 — 1 199 ₽/год |
| Пакет «Старт» (359 ₽) | **выключить** | дублирует уже оплаченный хостинг |
| Хостинг на 1 месяц (1 ₽) | **выключить**, если reg.ru даст выбрать существующий `u3692326` | хостинг уже есть; если оформление `.ru` без хостинга в заказе не пройдёт — оставьте, это 1 ₽ |
| Почта на домене (198 ₽/мес) | **выключить** | почта уже входит в тариф хостинга, ящик создаётся в панели |
| Переадресация домена (146 ₽/год) | **выключить** | редирект между доменами на одном хостинге — бесплатно, через панель |
| Антивирус для сайта (1 ₽/мес) | **выключить** | статический сайт без PHP — сканировать нечего |
| Электронное свидетельство о регистрации домена (203 ₽) | **по желанию** | ЭЦП, подтверждающая право на домен; пригодится при споре о домене и в госзакупках |
| DomainSSL (6 мес., бесплатно) | **не нужен** | на хостинге Let's Encrypt бесплатный и бессрочный, ставится в панели |

### Порядок действий после оплаты

**1. Привязать домены к хостингу** (панель reg.ru → Хостинг → `u3692326` → «Сайты»):

- «Добавить сайт» → указать домен → галочка **«Автоматически настроить DNS-серверы
  и записи зоны»** → «Подключить». Так DNS-записи создадутся сами.
- То же для `ai-ru-chating.ru` и `ruchating.ru`.

**2. Залить файлы**: файловый менеджер панели → `www/iiruchating.ru/` → загрузить
содержимое этой папки (или по FTP/SFTP). `.htaccess` положить в корень сайта —
он отдаёт `404.html`, включает gzip и ставит заголовки кэширования.

**3. Почта** (панель ispmanager → «Почта»):

- «Почтовые домены» → «Создать почтовый домен» → `iiruchating.ru` → Ok.
- «Почта» → «Создать ящик» → `hello` на домене `iiruchating.ru`.
- Затем в разделе «Почтовые домены» включить **DKIM**; SPF и DMARC добавить
  как TXT-записи в зоне домена.

> Отправка писем с IP виртуального хостинга Gmail и Яндекс часто уводит в спам —
> это общая проблема shared-хостингов. Для входящих заявок (`mailto:`) этого достаточно,
> но если позже понадобится рассылка от имени компании, лучше подключить отдельный
> сервис рассылок и настроить для него SPF/DKIM/DMARC, оставив на хостинге только
> приём почты.

**4. HTTPS**: «Сайты» → три точки у домена → «SSL-сертификаты» → «Новый Let's Encrypt
сертификат» → поставить галочки «Защищенное соединение (SSL)» и
**«Перенаправлять HTTP-запросы в HTTPS»**. Выпуск занимает до 24 часов.

**5. Редиректы** (бесплатно): «Сайты» → три точки у домена → «Настройка редиректов»:

| Источник | На адрес |
|----------|----------|
| `ruchating.ru` | `https://iiruchating.ru` |
| `www.iiruchating.ru` | `https://iiruchating.ru` |

**6. Идентификация через ЕСИА** — обязательна для `.ru`
(панель reg.ru → «Идентификация доменов»). Без неё домен приостанавливается.
Регистрировать лучше на **ООО/ИП**: в публичном WHOIS будет «ООО …», а не ФИО
и паспортные данные физлица.

**7. Обновить почту в лендинге**: сейчас стоит `hello@iiruchating.ru` —
в `index.html` (блок «Контакты») и в `assets/js/main.js` (адрес для `mailto:`).

### Альтернатива: VPS / облако reg.ru

```nginx
server {
    listen 80;
    server_name iiruchating.ru www.iiruchating.ru;
    root /var/www/iiruchating;
    index index.html;

    error_page 404 /404.html;

    location ~* \.(css|js|woff2|png|svg|ico)$ {
        expires 1y;
        add_header Cache-Control "public, immutable";
    }

    location / {
        try_files $uri $uri/ =404;
    }

    location ~ /\. { deny all; }
}

server {
    listen 443 ssl http2;
    server_name iiruchating.ru www.iiruchating.ru;
    # ssl_certificate     /etc/letsencrypt/live/iiruchating.ru/fullchain.pem;
    # ssl_certificate_key /etc/letsencrypt/live/iiruchating.ru/privkey.pem;
    root /var/www/iiruchating;
    index index.html;
    error_page 404 /404.html;
}
```

Бесплатный сертификат на VPS: Let's Encrypt через certbot либо панель reg.ru.

### DNS-записи

При привязке домена к хостингу через панель DNS-записи создаются автоматически
(галочка «Автоматически настроить DNS-серверы и записи зоны»). Вручную выглядит так:

| Домен | Тип | Значение | Назначение |
|-------|-----|----------|------------|
| `iiruchating.ru` | A | IP хостинга | основной сайт |
| `www.iiruchating.ru` | A | IP хостинга | редирект на основной |
| `ai-ru-chating.ru` | A | IP хостинга | сайт продукта |
| `ruchating.ru` | A | IP хостинга | короткий алиас → редирект на `iiruchating.ru` |

NS для доменов на хостинге reg.ru: `ns1.hosting.reg.ru` / `ns2.hosting.reg.ru`.
После смены IP хостинга A-записи обновлять не нужно, если NS делегированы на reg.ru.

### Редиректы

`ruchating.ru` → `iiruchating.ru` и `www.*` → без `www` настраиваются
бесплатно через панель хостинга (раздел **Сайты → три точки → Настройка редиректов**).
Альтернатива — `.htaccess` на стороне `ruchating.ru`:

```apache
Redirect 301 / https://iiruchating.ru/
```

## Что менять при доработке

| Задача | Файл |
|--------|------|
| Тексты, разделы, порядок блоков | `index.html` |
| Цвета отступы, сетка | `assets/css/styles.css` |
| Цвета бренда (primary/tertiary) | `assets/css/theme-m3.css` — только если меняется брендбук |
| Логотип/иконки | `assets/img/` — файлы из `ai-brand` |
| Почта в форме и контактах | `index.html` (`hello@iiruchating.ru`) + `assets/js/main.js` |
| Тексты в подвале, мета-теги | `index.html` |

**Форма заявки** сейчас формирует письмо через `mailto:` — бэкенд не нужен.
Если захотите принимать заявки напрямую с сайта, замените блок отправки
в `assets/js/main.js` на `fetch()` к вашему обработчику (reg.ru: «Скрипты» / PHP).

## Правила бренда, которые соблюдены

- Логотип только чёрный на светлом и белый на тёмном; инверсия через `filter: invert(1)`
  для `<img>` (брендбук, раздел 10.1).
- Полный логотип — не меньше 120 px по ширине (в шапке 132 px), иконка — не меньше 16 px.
- Цвета компонентов заданы ролями Material 3 (`--md-sys-color-*`), а не «голыми» HEX.
- Шрифты — Inter / Manrope / Montserrat, self-hosted, с кириллицей.
- Контраст «фон — текст» проверен: Lighthouse Accessibility 100 в светлой и тёмной темах.

Обновление брендкита: скопировать новые файлы из `ai-brand` в `assets/` (см. `INSTALL.md` брендкита).
