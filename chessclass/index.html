Возможности

ChessClass

Единая экосистема для школьников: Python-задачи с безопасной песочницей, шахматная лаборатория с разбором партий, конструктор ботов и карта навыков. Один профиль, один уровень и один LLM-ассистент на оба предмета.

Python-задачи

16 заданий с assert-тестами и лестницей подсказок. Код выполняется в RestrictedPython-песочнице: AST-отсечки, белый список импортов, лимиты памяти, времени и вывода.

Шахматная лаборатория

Stockfish 17.1, инсайт позиции (факты движка + объяснение LLM), PGN-анализ с детектом блюндеров и SSE-прогресс.

Конструктор ботов

Лестница random → greedy → minimax2 → Stockfish Elo 1400–1800, матчи на arq, Elo K=32 и лидерборд.

Карта навыков

11 навыков, недельные EMA, spider-график и рекомендации по кросс-доменным связям.

Классы и учитель

Инвайт-коды, групповой дашборд, назначения и отчёты. Роли student/teacher/admin/auditor, аудит действий и CSV-экспорт.

LLM-шлюз

RouterAI: DeepSeek, MiniMax, Beam и локальный fallback LM Studio. Квоты, бюджеты и FinOps по каждому вызову.

Архитектура

Один профиль на Python и шахматы

Ученик видит один уровень и одну карту навыков. Под капотом — FastAPI и React, PostgreSQL с pgvector, Redis, Stockfish и фоновые задачи arq.

Бэкенд

  • Python 3.12 + FastAPI — API, LLM-шлюз и домены Python/шахматы.
  • PostgreSQL 17 + pgvector — профили, задания, партии, навыки и RAG.
  • Redis 7 + arq — кэш, очереди и фоновые матчи/генерации.
  • Stockfish 17.1 — анализ позиций, боты и этюды.

Клиент и эксплуатация

  • React 19 + TypeScript — Vite-фронтенд: классы, задания, доска, дашборд.
  • Docker Compose — dev- и prod-стек, миграции Alembic, healthchecks.
  • LLM RouterAI — DeepSeek / MiniMax / Beam + локальный LM Studio.
  • PDF и аудит — отчёты родителям, CSV-экспорт и read-only аудитор.
