## 4. Готовые тексты карточек

### AI Ru Chating

**Статус:** `основной продукт · v0.16.0`

**Текст:** Рабочие пространства, публичные и приватные каналы, треды, реакции и личные сообщения в одном приложении. AI-ассистент живёт прямо в беседе, отвечает по вашим документам через RAG и не отправляет данные наружу: модель работает внутри вашего контура.

**Пункты:**
- Рабочие пространства, каналы, треды, реакции, закреплённые сообщения
- AI-ассистент участником беседы: SSE-стриминг, история запусков
- RAG по файлам пространства: эмбеддинги, PDF по страницам, OCR и vision
- Real-time на SignalR: сообщения, присутствие, набор текста, прочтение
- PWA, Web Push и e-mail-уведомления; SQLite, PostgreSQL и MSSQL

**Ссылка:** Сайт продукта → `ruchating.ru`

---

### AI Open Camera

**Статус:** `MVP в разработке`

**Текст:** Локальная AI-платформа видеонаблюдения: камеры разных производителей в одном интерфейсе, запись 24/7, распознавание людей, животных, птиц и машин, поиск событий по времени, камере, зоне и естественному языку.

**Пункты:**
- Камеры в локальной сети, RTSP-стримы, непрерывная запись
- Конвейер: детекция объектов → трекинг → эмбеддинги → события → поиск
- «Это Аня» — система запоминает человека по подсказке, а не по облачной базе
- MVP: камеры, live, запись, детекция, события, поиск и Telegram-уведомления

**Ссылка:** Сайт продукта → `ai-opencamera.iiruchating.ru`

### AI Ticket Buyer

**Статус:** `MVP · пилот`

**Текст:** Знакомится с интересами и собирает профиль вкуса, предлагает подходящие события и объясняет, почему они подходят. Следит за новыми датами, изменением цен и статусом продажи — и ведёт к покупке у официального продавца.

**Пункты:**
- Каталог: 13 площадок, 12 live-источников, fuzzy-матчинг событий
- Персональный скоринг по жанрам, площадкам, времени и бюджету
- Watch и дайджест: новые даты, изменения цен, статусы продажи
- Вход по email magic link, импорт билетов прямо из почты

**Ссылка:** Сайт продукта → `ai-ticketbuyer.iiruchating.ru`

### AI Workflow Builder

**Статус:** `v0.13.0`

**Текст:** Собирайте LLM-, агентные и интеграционные сценарии в визуальном редакторе: узлы соединяются мышью, собранный workflow запускается как API. Работает с вашими и внешними LLM, поддерживает MCP-инструменты.

**Пункты:**
- 22 типа узлов: LLM, агенты, HTTP, медиа, PDF/DOCX, MCP
- Импорт и экспорт сценариев, PDF-генерация, извлечение данных
- PostgreSQL + pgvector, S3, OpenTelemetry
- NestJS 12 · React 19 · workflow отдаётся по HTTP API

**Ссылка:** Сайт продукта → `ai-workflow-builder.iiruchating.ru`

### DzenWriter

**Статус:** `внутренний инструмент · E1–E11`

**Текст:** Проводит статью по конвейеру от идеи до публикации: план материалов, факт-база с одобрением ревьюера, генерация по стилям и версиям. Правило простое: нет факта — нет утверждения, а публикацию в Дзен подтверждает человек.

**Пункты:**
- Доска: Идея → Факты → Черновик → Ревью → Утверждено → Опубликовано
- Факт-гейт: материал не идёт на ревью без одобренных фактов
- Четыре стиля и форматы — YAML в git, правки через PR
- Версии неизменяемы, журнал аудита append-only, публикация вручную

**Ссылка:** Сайт продукта → `ai-dzenwriter.iiruchating.ru`
