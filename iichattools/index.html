Возможности

IIChatTools

IIChatTools даёт модели инструменты разработчика: файлы, Git/GitHub, HTTP, почту, браузер и базы данных. Multi-agent паттерны — Debate, Orchestrator-Worker, Reflection — выполняют задачи по шагам, а approvals и аудит оставляют человека в контуре.

Чат с локальной LLM

Razor-интерфейс со стримингом SSE, историей, ветками сообщений, экспортом и approvals. Модель подключается через OpenAI-совместимый API LM Studio.

73 инструмента

Файловая система, Git/GitHub, HTTP, SQL, почта IMAP/SMTP, браузер, RAG и планировщик. Модель сама выбирает инструмент в multi-turn цикле.

Multi-agent паттерны

Actor-Critic, Debate Pro/Contra/Judge, Orchestrator-Worker с Blackboard и Reflection. Сложная задача разбивается на роли и проверяемые шаги.

Approvals и песочница

Изменяющие действия требуют подтверждения: drag-and-drop, countdown, approve/reject. Пути и команды ограничены whitelist и TTL-сессиями.

RAG и знания

Семантический поиск по проектной документации, истории чатов и workspace. Четыре коллекции, auto-inject top-K в системный промпт.

Аудит и роли

Admin/User, изоляция workspace, журнал действий в БД и JSONL, RU/EN-интерфейс. Подключение MSSQL, SQLite или InMemory.

Архитектура

ASP.NET Core, LM Studio и песочница инструментов

Сервер на .NET 10 LTS принимает SSE-запросы, оркестрирует инструменты и хранит состояние. LLM работает рядом — в LM Studio или другом OpenAI-совместимом сервере.

Агентный слой

  • Tool Registry — 73 инструмента с whitelist путей и команд.
  • Multi-agent — sub-agent engine, Debate, Orchestrator + Blackboard, Reflection.
  • Security Sandbox — approvals, TTL-сессии, ограничение путей и аргументов.
  • RAG — 4 коллекции, эмбеддинги и auto-inject в system prompt.

Платформа

  • .NET 10 LTS — ASP.NET Core, Razor UI, EF Core 10, SSE.
  • LM Studio — OpenAI-совместимый API, локальная модель без облака.
  • MSSQL / SQLite — выбор провайдера, миграции и InMemory для тестов.
  • Docker + CI — образ на ghcr.io, сборка и тесты в GitHub Actions.
