IIRuChating — портфель продуктов

Пять основных продуктов и три новых направления — от корпоративного чата до шахматной школы. Продукты разные, но принципы общие: локальный AI там, где это важно, проверяемые результаты и человек в контуре принятия решений.

AI Ru Chating

Корпоративный мессенджер с локальным AI-ассистентом

основной продукт · v0.16.0

Рабочие пространства, публичные и приватные каналы, треды, реакции и личные сообщения в одном приложении. AI-ассистент живёт прямо в беседе, отвечает по вашим документам через RAG и не отправляет данные наружу: модель работает внутри вашего контура.

  • Рабочие пространства, каналы, треды, реакции, закреплённые сообщения
  • AI-ассистент участником беседы: SSE-стриминг, история запусков
  • RAG по файлам пространства: эмбеддинги, PDF по страницам, OCR и vision
  • Real-time на SignalR: сообщения, присутствие, набор текста, прочтение
  • PWA, Web Push и e-mail-уведомления; SQLite, PostgreSQL и MSSQL

AI Open Camera

Локальная AI-платформа видеонаблюдения

MVP в разработке

Объединяет камеры разных производителей в один интерфейс, пишет видео 24/7, распознаёт людей, животных, птиц и машины, учится узнавать «своих» по подсказке пользователя и ищет события по времени, камере, зоне и естественному языку.

  • Камеры в локальной сети, RTSP-стрими, непрерывная запись
  • Конвейер: детекция объектов → трекинг → эмбеддинги → события → поиск
  • «Это Аня» — система запоминает человека по подсказке, а не по облачной базе
  • MVP: камеры, live, запись, детекция, события, поиск и Telegram-уведомления

AI Ticket Buyer

Персональный ассистент по театрам и концертам

MVP · пилот

Знакомится с интересами и собирает профиль вкуса, предлагает подходящие события и объясняет, почему они подходят. Следит за новыми датами, изменением цен и статусом продажи — и ведёт к покупке у официального продавца.

AI Workflow Builder

Визуальный конструктор AI-сценариев

v0.13.0

Собирайте LLM-, агентные и интеграционные сценарии в визуальном редакторе: узлы соединяются мышью, собранный workflow запускается как API. Работает с вашими и внешними LLM, поддерживает MCP-инструменты.

  • 22 типа узлов: LLM, агенты, HTTP, медиа, PDF/DOCX, MCP
  • Импорт и экспорт сценариев, PDF-генерация, извлечение данных
  • PostgreSQL + pgvector, S3, OpenTelemetry
  • NestJS 12 · React 19 · workflow отдаётся по HTTP API

DzenWriter

Редакционный AI-конвейер для статей в Дзен

внутренний инструмент · E1–E11

Проводит статью по конвейеру от идеи до публикации: план материалов, факт-база с одобрением ревьюера, генерация по стилям и версиям. Правило простое: нет факта — нет утверждения, а публикацию в Дзен подтверждает человек.

  • Доска: Идея → Факты → Черновик → Ревью → Утверждено → Опубликовано
  • Факт-гейт: материал не идёт на ревью без одобренных фактов
  • Четыре стиля и форматы — YAML в git, правки через PR
  • Версии неизменяемы, журнал аудита append-only, публикация вручную

Принципы

Локальный AI — там, где это важно

Для ключевых продуктов — чата, видеонаблюдения, сценариев и образовательных решений — модель и данные остаются у вас. Где без облака не обойтись, мы говорим об этом прямо.

  • Ключевые продукты разворачиваются on-premise: LM Studio, vLLM или любой OpenAI-совместимый endpoint.
  • У них нет обязательной подписки: продукт работает на вашем железе и вашей модели.
  • Брендкит и часть инструментов открыты; репозитории — на GitFlic, зеркало на GitHub.
  • Данные не используются для обучения и не уходят третьим лицам без вашего согласия.

Бренд

IIRuChating

Один бренд на всю линейку: логотип, палитра Material 3, шрифты и правила оформления выложены в открытый доступ, чтобы продукты выглядели частью одного семейства и новые проекты начинались не с нуля.

Вариант В — цветные акценты в узоре. Для аватарок, стикеров и соцсетей.
