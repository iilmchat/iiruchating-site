Возможности

AI Teacher for Python

Интерактивный ассистент-учитель по Python для школьников 10–17 лет: три уровня помощи, безопасная песочница и задачи с автопроверкой. Учитель видит прогресс класса и назначает задания.

Три уровня помощи

Базовый — наводящие вопросы без готового кода. Средний — объяснение и пример синтаксиса. Продвинутый — полное решение с разбором.

Безопасная песочница

RestrictedPython и изоляция процесса: белый список модулей, лимиты времени, памяти и вывода, ограничение параллельных запусков.

Задачи с автопроверкой

6 готовых задач, тест-кейсы с input(), подсказки по одной и подробный отчёт. Импорт/экспорт JSON/YAML и генерация через LLM.

Классы и дедлайны

Создание класса, вступление по коду, назначения задач с дедлайнами, матрица прогресса и «мои задания».

Кабинет учителя

CRUD задач с конструктором тест-кейсов, импорт файла и прогресс учеников.

Надёжность LLM

Healthcheck провайдера, fallback «облако → локально», метрики латентности и токенов, детектор готовых решений.

Архитектура

Учитель, который не выдаёт ответ

Помощь строится по уровню: чем ниже уровень, тем больше вопросов и меньше готового кода. Классы, задачи и прогресс живут в одном контуре.

Бэкенд

  • Python 3.12 + FastAPI — API, чат и проверка задач.
  • PostgreSQL 17 + pgvector — пользователи, задачи, попытки и семантический поиск.
  • Redis — кэш справочников и очереди.
  • DeepSeek / LM Studio — облачная модель с локальным fallback.

Клиент

  • React 19 — чат, задачи, классы и кабинет учителя.
  • WebSocket + REST — стриминг ответов и резервный REST-фолбэк.
  • i18n RU/EN — интерфейс и подсказки на двух языках.
  • Docker Compose — PostgreSQL, Redis, API и фронтенд.
