Возможности

AI Workflow Builder

Собирайте LLM-, агентные и интеграционные сценарии в визуальном редакторе: узлы соединяются мышью, а собранный workflow запускается как API. Работает и с вашими, и с чужими LLM — провайдер задаётся в настройках.

22 типа узлов

LLM, агенты, HTTP, обработка данных, Share-файлы, импорт и экспорт сценариев — всё в одной палитре.

Данные из файлов

Извлечение данных из PDF и DOCX, эмбеддинги в PostgreSQL + pgvector — поиск по содержимому документов.

Workflow как API

Собранный сценарий отдаётся по HTTP API: один workflow — один endpoint, который зовут ваши сервисы.

Наблюдаемость

OpenTelemetry из коробки: трейсы, метрики и логи по каждому запуску — видно, где сценарий встал.

S3-хранилище

Крупные входы и выходы живут в S3, а не в базе: не раздувает PostgreSQL и не тормозит запуск.

Любой провайдер

Работает и со своими, и с чужими LLM — провайдер и модель задаются в настройках, а не в коде.

Архитектура

Редактор сценарного графа

Слева — палитра узлов, в центре — граф сценария, справа — настройки выбранного узла. Готовый workflow запускается как обычный HTTP-сервис.

Бэкенд

  • NestJS 12 — движок выполнения, версии и запуск workflow по HTTP.
  • PostgreSQL 17 + pgvector — сценарии, версии и векторный поиск по данным шагов.
  • S3 — хранение больших входов и выходов сценария.
  • OpenTelemetry — трейсы, метрики и логи каждого запуска.

Фронтенд и поставка

  • React 19 — графический редактор на React Flow.
  • 22 типа узлов — палитра LLM, агентов, HTTP и обработки данных.
  • Импорт и экспорт — сценарий можно вынести в файл и собрать заново.
  • Docker и GHCR — собранные образы публикуются в реестр и поднимаются в любой среде.

Статус

Production-версия

Сценарии собираются, запускаются и отдаются по API. Продукт работает в production на собственном хосте, с резервными копиями и мониторингом.

  • Стабильный набор из 22 типов узлов, версионирование сценариев и API запуска.
  • Backend и frontend покрыты автотестами, сборка и релизы идут через CI.
  • PostgreSQL 17 + pgvector, S3-хранилище, OpenTelemetry-observability.
  • Продукт коммерческий: доступ к редактору — по аккаунту, регистрация открыта.
